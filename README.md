# 💰 Smart Expense Tracker (Python)

A simple expense tracker built with Python and SQLite.

## Features

- ✅ Add expenses
- ✅ View expenses
- ✅ Delete expenses
- ✅ SQLite database
- ✅ Automatic expense categorization
- ✅ Total spending calculation
- ✅ Spending tips

## Technologies Used

- Python
- SQLite3

## How to Run

1. Clone the repository
2. Run:

```bash
python Expensetracker2.0.py
```
